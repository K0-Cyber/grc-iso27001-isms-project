# Supplier Security Policy

## Purpose

This policy establishes information security requirements for suppliers and third parties that access EugTech Solutions Ltd information, systems, or services.

It supports ISO/IEC 27001:2022 Annex A control A5.19 — Information Security in Supplier Relationships.

## Scope

This policy applies to suppliers and third parties that:

- Access EugTech systems
- Access company or client information
- Provide cloud or technology services
- Support systems included within the ISMS scope

## Supplier Security Assessment

Suppliers must be subject to an information security assessment.

The assessment process includes:

- Supplier security questionnaire
- Review of security requirements
- Documentation in the supplier register
- Review of contractual security provisions

## Supplier Agreements

Supplier and third-party access to EugTech systems or information must be governed by a signed agreement.

Relevant agreements must include appropriate information security requirements.

## Supplier Register

EugTech maintains a supplier register recording relevant suppliers and their security assessment status.

## Access Control

Supplier access must:

- Be authorised
- Be limited to the access required
- Follow least-privilege principles
- Be reviewed where appropriate
- Be removed when no longer required

## Non-Compliance

Where required supplier security information is not provided, the issue must be escalated.

Internal audit findings relating to incomplete supplier questionnaires must be tracked through corrective action.

## Review

Supplier security arrangements must be reviewed:

- During supplier onboarding
- When supplier services materially change
- Following a supplier security incident
- During ISMS audit and review activities

## Evidence

Implementation evidence includes:

- Supplier security questionnaires
- Supplier register
- Signed supplier agreements
- Contractual security clauses
- Supplier review records
